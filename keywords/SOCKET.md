# ソケット

## 説明

ソケットとは、ハードウェアとソフトウェアの両方でつなぐための入口として働く仕組みを指す言葉です。ハードウェアでは、CPU をはめ込む部分やケーブルを差し込む物理的なコネクタのことをいい、電気信号や電力をやりとりするための交換部分のことをいいます。一方、ソフトウェアの世界では、ネットワーク上でプログラム同士がやり取りを行うための通信の窓口を意味します。IPアドレスとポート番号という現実で言う住所のようなものを組み合わせることで通信相手を特定し、データを送ったり受け取ったりする際の窓口として機能します。このようにソケットは、物理・仮想のどちらでも機器やプログラム同士をつなぐ重要な役割を果たしています。例で言うと家のコンセントが電気の入り口であるようにソケットは情報の入り口となっています。
